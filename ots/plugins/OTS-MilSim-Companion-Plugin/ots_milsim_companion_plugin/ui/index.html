🎯 Assegna a missione

Il file viene scaricato da SkyFi sul server e aggiunto ai contenuti della missione: gli EUD iscritti ricevono la notifica e possono scaricarlo. Per file grandi (payload/COG) il trasferimento può richiedere qualche minuto.

▶ Prepara missione

I gruppi sono i gruppi ATAK definiti sul server (pagina Groups di OTS). Senza selezione la missione viene trasmessa a tutti gli EUD collegati. Con i gruppi: lo spawn A lo vede solo il Team A (+ osservatori), lo spawn B solo il Team B; bandiere, bomb site, punti di dominio, aree, chat e data package vanno a tutti i coinvolti.
